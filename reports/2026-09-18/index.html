文件更新・16 份

TDX 交通 API
查詢入口更清楚

這批既有 API 的知識與使用指引已校對。原始資料與服務由 TDX 提供，呼叫多需 TDX 帳號與金鑰；靜態、即時及歷史版本端點各有不同時間範圍，沒有共同的資料起訖年。

實際能查什麼公車 API 可取得路線站序、車輛位置與預估到站；捷運 v2 API 專屬捷運站點、票價和到離站；路段編碼 API 可查到如 2018Q3 的季別版本。台灣好行 API 提供觀光公車資訊，不是景點、餐飲與旅宿清單。

  1. 01
    TDX 市區公車 API（v2） ↗

    路線、站牌、站序、車輛位置與預估到站；另有即時推送端點。

    文件更新
  2. 02
    TDX 公共自行車 API（v2） ↗

    租借站基本資料、即時車輛與空位，以及自行車道路線形。

    文件更新
  3. 03
    TDX 捷運 API（v2） ↗

    捷運站點、路線、票價與即時到離站；這支 API 不含台鐵及高鐵。

    文件更新
  4. 04
    TDX 航空 API（v2） ↗

    機場、航班時刻、即時到離站、機場氣象與座位資訊。

    文件更新
  5. 05
    TDX 航運 API（v3） ↗

    港口、航線、船舶、班表、票價與即時到離港資訊。

    文件更新
  6. 06
    TDX 台灣好行觀光公車 API（v2） ↗

    台灣好行路線、站序、班表、票價與即時車輛；不含景點餐飲旅宿。

    文件更新
  7. 07
    TDX 公共運輸共通資料 API（v2） ↗

    文件更新
  8. 08
    TDX 行政區共通資料 API（v2） ↗
