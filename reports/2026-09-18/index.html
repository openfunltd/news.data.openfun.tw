分析 04・文化資產

現存名單近半認定於 2010 年代，
場域型以臺北、金門、臺南最多

13 類 API 中，形成或建造年代不是一致欄位，部分只寫在沿革文字；相較之下，公告中的「指定／登錄」日期有 6,405 筆可辨識。以下取每案最早一次指定或登錄日期，並另看可明確定位的場域型文化資產。

6,405／6,412可辨識首次指定／登錄年份完整率 99.9%
49.5%首次認定在 2010–2019 年3,171 筆
582 案臺北市場域型文資22 縣市中最多

和修法有關嗎？有制度上的關聯，但不能把 2010 年代的 49.5% 全部歸因於修法。2005 年修法 ↗擴大文化資產類別與中央統籌，2012 年文化部與文化資產局成立；2016 年全文修正 ↗再增列紀念建築、史蹟、口述傳統、傳統知識與實踐等類別，並要求既有公告依新分類重新指定、登錄及公告。這些變動增加了調查、分類與公告活動。不過本表只記個案最早公告日，2013 年高峰又主要來自古物批次認定，因此只能說時間上有關聯，不能從這份資料證明因果。

怎麼讀：認定年份呈現文化資產制度何時把個案納入保護；縣市筆數則呈現現存公開名單的空間分布。兩者都不能當成文化資產形成時間或地方文化價值的直接衡量。

蟋蟀與布穀聲，各自代表什麼？

API 回傳的是路口設施資訊；以下聲音的通行含義依交通部規範說明。

布穀聲

代表南北向行人綠燈，可以沿南北方向通行。

鳥叫聲

代表東西向行人綠燈，可以沿東西方向通行。

蟋蟀聲

代表行人專用時相，這段時間由行人通行。
